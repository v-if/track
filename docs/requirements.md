## 1. 프로젝트 개요

### 1.1 한 줄 소개

표준 400m 트랙에서 인터벌 훈련 시, **레인·바퀴·목표 시간(초)** 만 입력하면 **km 페이스(4:30/km 형식)** 로 환산하고, 동일 조건의 **1~8레인 페이스**를 비교해 보여 주는 오프라인 모바일 앱.

### 1.2 주 사용자·사용 맥락

| 항목 | 내용 |
|------|------|
| 주 사용자 | 아마추어 러너 |
| 사용 환경 | **집에서 사전 계산** (트랙 훈련 전 목표 페이스 확인) |
| 언어 | 한국어만 |
| 네트워크 | **오프라인 전용** (광고·서버·계정 없음) |

### 1.3 핵심 시나리오

| ID | 시나리오 | 설명 |
|----|----------|------|
| A | 단일 레인 계산 | 입력한 레인·바퀴·초 → 해당 레인 **분/km 페이스** 강조 표시 |
| B | 전 레인 비교 | 동일 바퀴·시간으로 **1~8레인** 페이스 목록 표시, **선택 레인만 강조**, 나머지는 참고 |

### 1.4 사용자 입력

| 필드 | 범위 | 기본값 | 비고 |
|------|------|--------|------|
| 레인 | 1 ~ 8 | 1 | 가로 버튼, 터치 1회 선택 |
| 바퀴 수 | 1 ~ 20 (정수) | 1 | |
| 목표 시간 | 1 ~ 3600초 (정수) | — | **초 단위만** (분:초 입력 없음) |

잘못된 값은 **입력 자체가 되지 않도록** 차단한다 (오류 토스트 최소화).

### 1.5 프로젝트 제약

| 항목 | 내용 |
|------|------|
| 범위 | MVP — 계산·표시·프리셋·최근값 저장 |
| 기간 | 4주 |
| 인력 | 1인 (기획·개발·디자인), AI 보조 개발 |
| 유지보수 | 런칭 후 변경 최소 — 로컬 계산·의존성 최소 |
| 플랫폼 | Flutter — **iOS / Android** 동시 출시 (둘 다 빌드 가능) |
| 4주 목표 | **Google Play · App Store** 스토어 출시 |
| 브랜딩 | 앱 이름·아이콘·스토어 문구 — **추후 결정** |

## 2. 확정된 도메인 규칙

### 2.1 트랙 규격

- **표준 400m 트랙, 8레인**
- 레인별 1바퀴 거리: **IAAF 표준 스태거 거리표** 고정 (변경 시 릴리즈 노트)

| 레인 | 1바퀴 (m) |
|------|-----------|
| 1 | 400.00 |
| 2 | 407.67 |
| 3 | 415.33 |
| 4 | 423.00 |
| 5 | 430.67 |
| 6 | 438.33 |
| 7 | 446.00 |
| 8 | 453.67 |

### 2.2 계산식

```
총거리(m)     = 레인별_1바퀴거리 × 바퀴수
페이스(초/km) = 목표시간(초) × 1000 / 총거리(m)
표시          = floor(초/km ÷ 60) : (round(초/km) % 60)  → 예: 3:45/km
```

- **표시 단위**: km 페이스만 (`4:30/km` 형식, 초 단위 반올림 후 표시)
- **부가 지표 없음**: km/h, m/s, 5K/10K 예상 기록 등 제외

### 2.3 전 레인 비교 규칙

- 항상 **1~8레인 전체** 표시
- **선택 레인**: 강조(굵게·배경·테두리 등 — `spec.md` 참고)
- 나머지 레인: 참고용 일반 스타일

동일 시간·바퀴일 때 **바깥 레인일수록 1바퀴 거리가 길어** 같은 시간에 더 많은 거리를 달리므로, **페이스 숫자(분/km)는 작아진다**(더 빠른 페이스). 예: 1바퀴 90초 → 1레인 3:45/km, 8레인 3:18/km.

## 4. MVP 기능 범위

### 4.1 Must Have

- [x] 레인(1~8 가로 버튼), 바퀴(1~20, 기본 1), 시간(초) 입력
- [x] 유효 범위 밖 값 입력 차단
- [x] 선택 레인 km 페이스 실시간 표시 (`M:SS/km`)
- [x] 1~8레인 페이스 비교 목록 (선택 레인 강조)
- [x] 표준 스태거 거리표 기반 계산
- [x] 훈련 **프리셋** 버튼 (바퀴·시간 빠른 적용)
- [x] 마지막 입력값 **로컬 저장·복원**
- [x] 오프라인, 로그인·권한 없음
- [x] 한국어 UI, 라이트 테마, 트랙 경기장 컬러
- [x] iOS / Android 스토어 제출 가능 빌드

### 4.2 Should Have

- (없음 — MVP 범위에 프리셋·로컬 저장 포함 완료)

### 4.3 Could Have (v1.0 이후)

- 사용자 정의 트랙/레인 거리
- 프리셋 편집·다중 히스토리
- 분:초 시간 입력
- 다크 모드·시스템 테마
- 결과 클립보드 공유
- 다국어

- km/h, 랩타임 외 부가 지표
- 소셜·코치·서버 동기화
- 광고·푸시·크래시 분석
- 다크 모드

## 6. 수용 기준 (Acceptance Criteria)

| # | Given | When | Then |
|---|--------|------|------|
| AC1 | 1레인, 1바퀴, 90초 | 앱 표시 | 페이스 **3:45/km** (±0초) |
| AC2 | 8레인, 1바퀴, 90초 | 앱 표시 | 페이스 **3:18/km** (±0초) |
| AC3 | 1레인·8레인, 동일 1바퀴 90초 | 비교 | 8레인 페이스 **&lt;** 1레인 (더 빠름, 분/km 숫자 작음) |
| AC4 | 레인 3 선택 | 전 레인 목록 | 3레인 행만 강조 스타일 |
| AC5 | 바퀴 25 입력 시도 | — | 입력 불가 또는 최대 20으로 제한 |
| AC6 | 시간 0 또는 빈 값 | — | 계산 결과 미표시 또는 기본 안내 |
| AC7 | 값 변경 | — | **즉시** 결과·목록 갱신 (버튼 없음) |
| AC8 | 입력 후 앱 종료·재실행 | — | 마지막 레인·바퀴·초 복원 |
| AC9 | 프리셋 "1바퀴 90초" 탭 | — | 바퀴=1, 시간=90 반영 |
| AC10 | 비행기 모드 | 모든 기능 | 정상 동작 |

기대값 상세: [`spec.md` §6](./spec.md#6-계산-검증-기대값).
